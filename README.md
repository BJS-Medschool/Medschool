# MedPrep — UHS MBBS MCQ Trainer

This is a beginner-friendly MCQ website made with:
- HTML
- CSS
- JavaScript

## How to use it

1. Open `index.html` in a browser.
2. Choose a subject and module.
3. Choose the number of questions.
4. Start the test.

## How to add questions

Open `questions.js`.

Copy one question object and change:
- subject
- module
- difficulty
- question
- options
- answer
- explanation
- reference

Remember:
- answer 0 = A
- answer 1 = B
- answer 2 = C
- answer 3 = D
- answer 4 = E

## How to put it online

The easiest route is GitHub Pages:
1. Create a GitHub account.
2. Create a new repository.
3. Upload all four files.
4. Open Settings → Pages.
5. Select the main branch and root folder.
6. Save.

GitHub will provide a public website address.

For a beginner, do not worry about understanding all the code yet. You can mainly work with `questions.js` to build your question bank.
